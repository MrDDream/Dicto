## Nouveautés

Les vocaux WhatsApp se transcrivent sans passer par Partager. Dans Dicto › Fichier audio, autorise une fois le dossier des vocaux de WhatsApp, puis :

- **Dernier vocal en un toucher.** Ajoute la tuile « Dernier vocal » aux réglages rapides : tu écoutes un vocal, tu tires le volet, un toucher, et le texte s'affiche par-dessus WhatsApp. Le bouton existe aussi dans Dicto.
- **Liste des vocaux récents.** Les derniers vocaux du dossier, un toucher pour transcrire, l'aperçu du texte pour ceux déjà faits (sans les retranscrire).
- **Transcription automatique (option).** Chaque vocal reçu est transcrit seul, et le texte arrive en notification « Vocal de … », avec Copier et Partager. Dicto ne lit que les notifications de WhatsApp. Si Android affiche « Paramètre restreint », passe par les infos de Dicto › ⋮ › « Autoriser les paramètres restreints ».

Les vocaux transcrits vont dans l'historique.

## What's new

WhatsApp voice messages can be transcribed without going through Share. In Dicto › Audio file, allow the WhatsApp voice messages folder once, then:

- **Last voice message in one tap.** Add the "Last voice message" tile to quick settings: listen to a voice message, pull down the panel, one tap, and the text shows over WhatsApp. The button is in Dicto too.
- **Recent voice messages.** The latest voice messages in the folder, one tap to transcribe, a preview of the text for those already done (without transcribing them again).
- **Automatic transcription (optional).** Each voice message you receive is transcribed by itself and the text arrives as a "Voice message from …" notification, with Copy and Share. Dicto only reads WhatsApp notifications. If Android says "Restricted setting", go to Dicto's app info › ⋮ › "Allow restricted settings".

Transcribed voice messages go to the history.
